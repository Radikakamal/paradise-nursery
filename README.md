# Paradise Nursery

Paradise Nursery is a React-based online plant shop where users can browse plants, add plants to a shopping cart, manage quantities, remove items, and proceed to checkout.

## Features

- Landing page for Paradise Nursery
- Browse plants by category
- Add plants to cart
- Increase and decrease plant quantities
- Remove plants from cart
- View total cart amount
- Continue shopping
- Checkout functionality
- Responsive design

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite

## Project Purpose

The project demonstrates a plant shopping application built using React and Redux for state management.
